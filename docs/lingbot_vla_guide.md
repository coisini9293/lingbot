# Lingbot-VLA 通俗说明文档

> 写给完全零基础的朋友：什么是 Lingbot-VLA，它是怎么工作的，能做什么。

---

## 一、一句话概括

**Lingbot-VLA 是一个"看一眼就会干活"的机器人 AI 系统。**

你只需要用手柄操控机械臂做几次示范，它就能学会自己做同样的事情。

---

## 二、核心原理 — 用类比来理解

### 2.1 什么是 VLA？

VLA = **V**ision（视觉）+ **L**anguage（语言）+ **A**ction（动作）

想象你教一个小朋友叠衣服：

1. **眼睛看**（Vision）→ 小朋友看到你怎么做
2. **耳朵听**（Language）→ 你告诉他"把衣服叠好"
3. **手做**（Action）→ 小朋友模仿你的动作

Lingbot-VLA 就是这样一个"AI 小朋友"：
- 它有 3 个摄像头当"眼睛"
- 你能用自然语言告诉它任务（比如"把黑色方块拿起来"）
- 它会控制机械臂去完成任务

### 2.2 它是怎么学会的？

```
┌─────────────────────────────────────────────────────┐
│  学习阶段（训练）                                      │
│                                                       │
│  你用手柄操控机械臂 → 系统记录你的操作 → AI 从中学规律  │
│                                                       │
│  类比：看老师做了10遍数学题 → 自己也会做了              │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│  使用阶段（部署）                                      │
│                                                       │
│  AI 看到当前画面 + 听到任务指令 → 自己算出该怎么动      │
│                                                       │
│  类比：考试时看到新题 → 用学过的方法解题                │
└─────────────────────────────────────────────────────┘
```

### 2.3 为什么叫"4B"模型？

"4B" = 40 亿（Billion）个参数。

参数就像大脑里的神经连接，连接越多，能处理的问题越复杂。
40 亿参数大约相当于人脑神经连接数的万分之一，但已经足够处理简单的操控任务了。

### 2.4 Step 与 Epoch：训练进度怎么理解

训练时你会看到两种计数，**不要混为一谈**：

| | Step（步） | Epoch（轮） |
|---|-----------|------------|
| **什么意思** | 模型**改了一次参数** | 所有示范数据**完整学了一遍** |
| **类比** | 做完一组题，订正一次错题本 | 把整本练习册从头到尾做一遍 |
| **本项目** | 正式训练跑 **1024 step** | 约等于 **2.7 遍**数据（1024÷373） |

**为什么我们更常用 Step？**

1. 配置里写的是 `max_steps: 1024`，到 step 1024 就停，不是「跑 20 轮」。
2. 保存的模型文件夹叫 `global_step_1024`，loss 曲线横轴也是 Step。
3. 训练可能在「第 2.7 轮」中间结束，**轮数经常不是整数**，不如 step 准确。

**记住一句：** Step 数参数更新次数，Epoch 数数据看了几遍；**看进度、存模型、画图，都以 Step 为准。**

详细换算与命令见 [environment_setup.md — Step 与 Epoch](environment_setup.md#五附step-与-epoch-的区别)。

## 三、数据收集 — 怎么教它

### 3.1 需要什么设备

```
┌──────────────────────────────────────────┐
│  硬件清单                                 │
│                                           │
│  1. SO-100 机械臂 ×2（一大一小）          │
│     - 大的叫 "leader"（主臂，你手操控）    │
│     - 小的叫 "follower"（从臂，实际执行） │
│                                           │
│  2. 摄像头 ×3                             │
│     - 顶部摄像头（看全局）                │
│     - 左手腕摄像头（看手的位置）          │
│     - 右手腕摄像头（看另一个角度）        │
│                                           │
│  3. 电脑                                  │
│     - 采集数据用普通电脑即可              │
│     - 训练需要 2 块 48GB 显卡             │
└──────────────────────────────────────────┘
```

### 3.2 采集过程

就像用游戏手柄玩"机器人版的遥控赛车"：

1. 你操控 leader 臂（主臂），follower 臂（从臂）会完全模仿你的动作
2. 3 个摄像头同时录像，记录机械臂看到的画面
3. 系统把"画面 + 你的动作 + 任务描述"打包成一条训练数据
4. 重复做 5-20 次同样的任务

**关键点**：你做得越规范、越多样，AI 学得越好。

### 3.3 关于摄像头

摄像头可以是**外接 USB 摄像头**，不需要特殊型号。

只要满足：
- 分辨率：640×480 或更高
- 帧率：30 FPS
- **时间对齐**：三个摄像头的画面必须是同一时刻的

系统会自动处理时间对齐，你只需要确保摄像头连接稳定。

## 四、训练过程 — AI 怎么学

### 4.1 训练的本质

训练就是让 AI 反复看你的示范数据，找到"看到什么画面 → 做什么动作"的规律。

```
输入：3张摄像头图片 + "拿起黑色方块"这句话
     ↓
AI 模型（40亿参数的神经网络）
     ↓
输出：6个数字（5个关节角度 + 1个夹爪开合）
```

### 4.2 训练需要什么

| 项目 | 要求 |
|------|------|
| GPU | 2 块 NVIDIA 48GB 显卡（A6000/RTX 6000 等） |
| 数据 | 5-20 个 episode（每个约 150 帧） |
| 时间 | 约 1024 步，几小时到一天 |
| 存储 | 几十 GB（模型 + 数据） |

### 4.3 训练的步骤

```
原始数据 → 计算归一化统计量 → 开始训练 → 保存检查点
   │              │                │            │
   │              │                │            └→ 可用于部署的模型
   │              │                └→ AI 反复学习数据中的规律
   │              └→ 把数据缩放到统一范围（像把考试分数标准化）
   └→ 你采集的示范视频和动作
```

## 五、部署效果 — 训练好后能做什么

### 5.1 工作流程

训练好模型后，系统的工作流程是：

```
每秒 30 次循环：
  1. 拍照（3个摄像头各拍一张）
  2. 把照片发给 AI 模型
  3. AI 计算出机械臂该怎么动
  4. 机械臂执行动作
  5. 回到第 1 步
```

### 5.2 效果演示

- ✅ 能做：你训练过的任务（比如"拿起黑色方块"）
- ✅ 能做：任务描述变化（比如换个颜色的方块）
- ⚠️ 有限：完全没见过的物体会失败
- ❌ 不能：超出机械臂物理范围的动作

### 5.3 推理方式

模型可以通过 **WebSocket** 远程推理：
- 机械臂的电脑只需要发图片，不需要 GPU
- AI 模型跑在远程服务器上
- 延迟约 30ms，对 30Hz 的控制频率足够

## 七、常见问题

### Q: 没有机械臂能玩吗？
**A:** 可以！使用开源数据集 `svla_so101_pickplace` 直接在 AutoDL 上微调训练，详见 `docs/environment_setup.md`。

### Q: 需要很强的编程能力吗？
**A:** 不需要。整个流程已经封装好了，只需要按顺序运行 Python 脚本。

### Q: 一个任务需要采集多少数据？
**A:** 建议 5-20 个 episode。简单任务 5 个就够，复杂任务需要更多。

### Q: 训练要多久？
**A:** 用 2 块 48GB 显卡，1024 步大约几小时。

### Q: 摄像头有特殊要求吗？
**A:** 普通 USB 摄像头即可，支持 640×480@30fps 就行。三个摄像头的画面需要时间对齐。

### Q: 能同时做多个任务吗？
**A:** 可以！采集不同任务的数据，训练时模型会学会根据语言指令切换任务。
